# HidakaSFL

Next.js 14 (App Router, TypeScript). API key hanya dipakai di server (`app/api/bypass/route.ts`).

## Jalankan
1. `npm install`
2. Salin `.env.example` jadi `.env.local`, isi `ZAPI_KEY`
3. `npm run dev`

## Deploy (Vercel)
Import repo GitHub, lalu tambah Environment Variable `ZAPI_KEY` di Settings. Deploy.
